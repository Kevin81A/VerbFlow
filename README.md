# VerbFlow — Domina los Tiempos Verbales en Inglés

Aplicación web interactiva y pedagógica para aprender y practicar los tiempos verbales en inglés (Present Continuous, Past Continuous, Future Simple, Present Simple, Past Simple, Future Continuous, Present Perfect, y Desafío Mixto).

## 🚀 Características
- **Modo Estudio:** Explicaciones claras en español, líneas de tiempo visuales, fórmulas divididas por componentes y pronunciación con audio nativo.
- **Modo Práctica:** Ejercicios de opción múltiple, ordenamiento de oraciones (Word Scramble), completar palabras y caza de errores.
- **Gamificación:** Sistema de XP, racha de aciertos (Streak) y guardado de progreso en el navegador.
- **Chuleta rápida:** Resumen imprimible de fórmulas.
- **Tema Claro / Oscuro.**

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Variables, diseño responsivo, animaciones)
- JavaScript Vanilla ES6+ (Web Speech API, LocalStorage)
